# DayMode

Android-приложение режима дня (Kotlin + Jetpack Compose).

## Что уже есть (этапы 1–2)

- Онбординг: подъём, начало работы/учёбы, график 5/2 или свои дни, отбой, за сколько до сна напоминание
- Главная «Сегодня»: сейчас / дальше / лента якорей
- Заглушки Утро / Вечер
- Настройки с локальным сохранением (DataStore)
- Без сервера

## Дальше

- Блоки дня («+ Добавить») с днями недели
- Трекер утренних/вечерних привычек
- Уведомление по времени в окне без телефона
- Мягкое уведомление при разблокировке в этом окне

## Открыть в Android Studio

1. File → Open → `D:\AndroidStudioProjects\DayMode`
2. Дождаться Gradle Sync
3. Run на эмуляторе или телефоне

SDK: `D:\Android\android-sdk` (см. `local.properties`)
